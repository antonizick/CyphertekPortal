# Portal Page

A personal dashboard/portal page with a glassmorphism design and dark theme.

## Features

- **Glassmorphism UI** — Frosted-glass cards with backdrop blur effects
- **Responsive Layout** — CSS Grid-based layout with 5-column rows on desktop, collapsing to 3 columns on narrow screens and a full-width accordion on mobile
- **Mobile Navigation** — Hamburger menu with accordion sections for touch devices
- **Dropdown Menus** — Hover-triggered desktop navigation with accessible focus states
- **40 Direct Shortcuts** — Organized into 8 rows: Search, Mail, Music & Video, Home & Work, Photos & Storage, Games, Social, Finance

## Tech Stack

- HTML5
- CSS3 (Grid, Flexbox, CSS Variables, Backdrop Filter)
- Vanilla JavaScript (ES6+, no dependencies)
- Google Fonts (Rajdhani, Inter)

## Structure

```
index.html   — Single-page application with all HTML, CSS, and JS inline
screenshots/ — Screenshots of the portal page
```

## Usage

1. Open `index.html` in a browser
2. Click the card links to navigate to external services
3. On mobile, use the hamburger menu (top-right) for navigation

## Browser Support

All modern browsers with support for CSS backdrop-filter and CSS Grid.
